## Capture checklist

1. Start the exact local source release being documented; record commit/release marker and browser/version. Do not use production/hosted systems without separate authorization.
2. Use only fictional usernames, fictional subjects/topics, and synthetic session values. Remove browser profile names, account emails, notifications, URL query secrets, OS identity, and developer tools from the frame.
3. Capture both a desktop baseline (1440×900) and a phone baseline (390×844), plus a tablet width if showing a responsive transition.
4. Check for private records, credentials, environment values, debug output, and personal browser chrome before saving.
5. Name captures by feature and viewport (for example `dashboard-desktop-1440x900.png`); add the actual date, environment, source release, browser, and verification action to the table above.
6. Verify each image is an actual rendered application page. Do not label wireframes, generated logos, or component mockups as app screenshots.
