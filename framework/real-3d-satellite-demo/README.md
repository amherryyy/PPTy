# Real 3D Satellite Slide Study

One-slide workflow proof using an original Blender model and a separately authored HTML/CSS slide.

## Files

- satellite.blend — editable original scene
- build_satellite.py — procedural modeling and render setup
- satellite.png — transparent rendered 3D asset (2400 × 1600)
- index.html — editable HTML/CSS slide text and labels
- render.cjs — Playwright 4K export and basic canvas/image preflight
- satellite-slide-4k.png — final 3840 × 2160 slide image

The spacecraft is a conceptual visual study, not an engineering-accurate spacecraft model. Its labels are HTML text; the 3D scene contains no baked typography. Geometry, materials, camera, lighting, and render settings are preserved in the Blender file.
