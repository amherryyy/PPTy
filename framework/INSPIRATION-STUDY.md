## Dimensional assets

`assets/dimensional/glass-learning-loops.png` is an original AI-generated 3D-looking raster illustration. It is an image, not a rotatable 3D mesh or an editable PowerPoint object. Its purpose is an abstract visual accent; it is not evidence of a real device or scientific phenomenon. Use `object-fit: contain`, preserve aspect ratio, and check contrast against the chosen background. Validate transparency before relying on it for compositing.

## Reuse rules

- Select visual treatment based on audience, subject and approved material. Six semantic layout families and source fidelity remain the framework architecture.
- Use title, explanation, comparison, process, table, chart and closing compositions as content requires. No recurring header/footer by default.
- For data and diagrams use verified values and honest relationships. Illustration is decorative or conceptual unless clearly supported by the source.
- Dimensional effects may be raster illustrations or CSS lighting; neither should be represented as editable 3D geometry. True 3D assets and native editable PPTX are not currently implemented.
- Inspect each slide at full size, check clipping, contrast and content, and record source references. Do not claim PNG packaging creates editable PowerPoint content.
