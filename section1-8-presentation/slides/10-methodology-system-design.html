DATABASE DESIGN

Eight core academic tables

Ownership-aware links connect each student's subjects, topics, plans, and sessions.

usersPK idusername · academic program
subjectsPK id · FK user_idname · program_id
study_sessionsPK id · FK user_idsubject_id · topic_id?
study_plansPK id · FK user_idplan_date · available_minutes
check_insPK id · FK user_idworkload_rating · energy_rating
student_streak_daysPK id · FK user_idactivity_date · streak_days
topicsPK id · FK user_idsubject_id · title · due_date
study_plan_itemsPK id · FK user_idplan_id · topic_id?
Relationships1 user to many subjects, topics, sessions, plans, check-ins, and streak days. 1 subject to many topics; 1 plan to many plan items. Composite ownership keys keep linked records within the same user. Topic links marked "?" are nullable.
